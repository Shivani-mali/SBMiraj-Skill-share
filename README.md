## ✨ Exciting Features

We developed a web solution packed with exciting features:
* 🌐 **Personalized Student Profiles**: Personalized profile pages to connect with others.
* 🎥 **Video Call Integration**: Direct connection capabilities designed for remote tutoring and collaboration.
* 🤖 **AI Chatbot**: An integrated smart assistant to guide beginners and answer queries.
* 📋 **To-Do Section**: A built-in task tracker for personal task tracking and learning milestones.
* 📚 **Google Classroom Integration**: Direct access to notes and class materials.
* 📺 **"Skill Gain" Tab**: Domain-specific YouTube learning resources.

## 🛠️ Technology Stack & Architecture

This repository contains two complete architectural versions of the project, available on different branches:

### 1. Serverless Firebase Architecture (Branch: `main`)
The primary, active version of the application running entirely in the browser using backend-as-a-service.
* **Frontend**: HTML5, CSS3 (Modern UI), Vanilla JavaScript.
* **Backend & Auth**: Firebase Authentication.
* **Database**: Firebase Cloud Firestore (NoSQL).
* **Hosting**: Firebase Hosting.

### 2. Traditional LAMP Stack (Branch: `php-version-backup`)
The original backend architecture of the project.
* **Frontend**: HTML5, CSS3, JavaScript.
* **Backend**: PHP.
* **Database**: MySQL.
